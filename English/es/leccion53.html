Lección 53 · The Last Will Be First Nivel A2 · Pre-intermedio

Comparativos y superlativos irregulares: good → better → best, bad → worse → worst, far → farther → farthest

Vocabulario nuevo: 12 · Acumulado: 650 / 1200
1. Watch · Objetivos y resumen

🎯 Objetivo principal

Aprender los comparativos y superlativos irregulares más comunes del inglés: good → better → best, bad → worse → worst, far → farther → farthest. Estos adjetivos no siguen las reglas normales y deben memorizarse.

📌 Subobjetivos

  • Usar el comparativo better than (mejor que).
  • Usar el superlativo the best (el mejor).
  • Usar el comparativo worse than (peor que).
  • Usar el superlativo the worst (el peor).
  • Usar farther than y the farthest.
  • Comprender el versículo “The last will be first, and the first will be last” (Mateo 20:16).
En esta lección aprenderás los comparativos y superlativos irregulares. Good → better → best (bueno → mejor → el mejor). Bad → worse → worst (malo → peor → el peor). Far → farther → farthest (lejos → más lejos → el más lejos). Practicarás con el versículo: "The last will be first, and the first will be last" (Mateo 20:16). Jesús invierte los valores del mundo: los últimos serán primeros. Al final, podrás usar estos irregulares para comparar personas, cosas y situaciones.
In this lesson, you will learn the irregular comparatives and superlatives. Good → better → best. Bad → worse → worst. Far → farther → farthest. You will practice with the verse: "The last will be first, and the first will be last" (Matthew 20:16). Jesus reverses the values of the world: the last will be first. By the end, you will be able to use these irregulars to compare people, things, and situations.
Observa: En “The last will be first, and the first will be last”, Jesús usa last y first como adjetivos. En esta lección aprenderemos a decir “better” (mejor), “the best” (el mejor), “worse” (peor), etc.

6. Grammar · Comparativos y superlativos irregulares

🔹 Comparativos y superlativos irregulares

Algunos adjetivos tienen formas especiales que no siguen la regla de añadir -er o more. Estos son los más comunes:

good
→ better
→ the best
bueno
bad
→ worse
→ the worst
malo
far
→ farther
→ the farthest
lejos
good → better → best

God is good.

He is better than me.

He is the best.

bad → worse → worst

The news was bad.

Things got worse.

That was the worst.

far → farther → farthest

He lives far.

He lives farther than me.

He lives the farthest.

Reglas clave:
  • good → better → best (bueno → mejor → el mejor)
  • bad → worse → worst (malo → peor → el peor)
  • far → farther → farthest (lejos → más lejos → el más lejos)
  • Estas formas son irregulares y deben memorizarse.
  • El comparativo siempre usa than; el superlativo usa the.
En contexto bíblico: Jesús dice: “The last will be first, and the first will be last.” En el Reino de Dios, los valores se invierten. Aprendemos a usar better, best, worse, worst para entender esta lógica divina.
